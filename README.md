# موسوعة السادس

تطبيق Android (Kotlin + Jetpack Compose + Room) لمنهج السادس الإعدادي العراقي: قارئ الكتاب، مختبر ثلاثي الأبعاد،
بنك الأسئلة الوزارية، وخطة الـ 100. الفصل الأول من كل مادة مجاني، وباقي الفصول تُفتح بكود اشتراك.

## البناء

المتطلبات: JDK 17 أو أحدث، و Android SDK 36.

```bash
./gradlew assembleDebug        # نسخة التطوير
./gradlew testDebugUnitTest    # الاختبارات
./gradlew assembleRelease      # نسخة الإصدار (تحتاج KEYSTORE_PATH و STORE_PASSWORD و KEY_PASSWORD)
```

نسخة الإصدار مفعّل فيها R8 (تصغير الكود والموارد).

## أكواد التفعيل

التطبيق **لا يحتوي على الأكواد**، بل على بصمة SHA-256 لكل كود فقط في
`app/src/main/assets/vouchers/voucher_registry.txt`، فلا يمكن استخراج كود صالح من ملف الـ APK.
كل كود فيه 80 بت عشوائية (16 حرفاً بصيغة `XXXX-XXXX-XXXX-XXXX`)، لذا لا يمكن تخمينه.

لتوليد دفعة أكواد:

```bash
# الباقة الشاملة (7 مواد)
python3 tools/generate_vouchers.py --plan ALL_7_SUBJECTS_VIP_ANNUAL --count 500 --expires 2027-09-30

# كتاب واحد (islamic, arabic, english, math, biology, physics, chemistry)
python3 tools/generate_vouchers.py --plan SINGLE_SUBJECT_ANNUAL --subject physics --count 200 --expires 2027-09-30
```

- الأكواد تُحفظ في `tools/generated_vouchers/*.csv` (مستثنى من git). **لا ترفعه للمستودع أبداً.** وزّعه على المكتبات أو أرسل الكود للطالب بعد الدفع.
- البصمات تُضاف تلقائياً إلى سجل التطبيق. ارفع السجل وأصدر نسخة جديدة من التطبيق حتى تعمل الأكواد الجديدة.

### حدود التحقق المحلي (Offline)

التحقق يعمل بدون إنترنت، لذلك:
- **الكود الواحد يمكن استخدامه على أكثر من جهاز.** منع ذلك يحتاج خادماً يسجّل الأكواد المستخدمة (مثلاً Firebase Functions + Firestore).
- من يعدّل ملف الـ APK أو ساعة الجهاز يستطيع تجاوز القفل. الحماية الكاملة تحتاج إبقاء المحتوى المدفوع على خادم.

## المختبر ثلاثي الأبعاد

مكتبات three.js r128 و model-viewer 3.5.0 مضمّنة في `app/src/main/assets/vendor/` (مع تراخيصها)،
وتُقدَّم عبر `WebViewAssetLoader`، فيعمل المختبر بدون إنترنت. أي طلب لعنوان خارجي من داخل الـ WebView يُحجب.

## قاعدة البيانات

- الإصدار الحالي 3. الترحيل من 2 → 3 (`MIGRATION_2_3`) يحافظ على تقدّم الطالب وملاحظاته.
- المخطط يُصدَّر إلى `app/schemas/` عند البناء. **ارفع هذا المجلد** وأضف `Migration` صريحاً عند أي تغيير قادم.

## المحتوى

المحتوى الحالي عيّنة (حوالي 17 صفحة لكل المواد). إكمال الكتب يتم بإضافة صفحات `TextbookPage` في ملفات `data/`،
بعد التأكد من دقة النصوص والأجوبة ومن حقوق نشر نص الكتاب المدرسي.
