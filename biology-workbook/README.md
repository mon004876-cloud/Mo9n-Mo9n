# Biology Coloring Workbook — توليد الرسومات بـ Gemini

30 رسمة أحياء للثانوية (Grades 9–12)، ونفس الرسومات تنفع للنسخة العربية للمنهج العراقي.

## الملفات

| الملف | شنو بيه |
|---|---|
| `topics.json` | الـ30 موضوع، وكل جزء بالرسمة مكتوب بالإنجليزي والعربي |
| `PROMPTS.md` | البرومبتات جاهزة للنسخ واللصق بتطبيق Gemini |
| `generate.py` | سكربت يولّد الـ30 صورة مرة وحدة عن طريق Gemini API |

## الطريقة 1: بدون برمجة (تطبيق Gemini)

1. افتح `PROMPTS.md`.
2. انسخ البرومبت الأول والصقه بـ Gemini.
3. احفظ الصورة باسم `01_animal_cell.png`، وكمّل للصورة الجاية.

## الطريقة 2: كل الصور مرة وحدة (Gemini API)

```bash
pip install google-genai
export GEMINI_API_KEY="المفتاح مالتك"     # تجيبه من https://aistudio.google.com/apikey
cd biology-workbook
python generate.py              # يولّد كل الصور بمجلد output/
python generate.py --only 16 23 # يعيد صفحات معينة بس
python generate.py --force      # يكتب فوق الصور الموجودة
```

ملاحظات:
- إذا Google غيّرت اسم موديل الصور، حدّده هيج: `export GEMINI_IMAGE_MODEL=...`
- توليد الصور عن طريق الـ API ممكن يحتاج حساب مفعّل بيه الدفع (billing).

## ليش الرسمة بدون أي كتابة؟

البرومبت يطلب رسمة بدون أي نص، لسببين:
1. الذكاء الاصطناعي يغلط هواية بكتابة الأسماء، وخصوصاً العربي.
2. بعدين نضيف الأرقام والأسماء بطبقة منفصلة. الإنجليزي للنسخة الأمريكية والعربي للنسخة العراقية، وجدول الأسماء كله جاهز بـ `topics.json`.

تأكد من كل صورة علمياً قبل لا تعتمدها، لأن الذكاء الاصطناعي أحياناً يرسم تفاصيل غلط (عدد حجرات القلب، اتجاه الأوعية، وغيرها).
